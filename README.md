# Guardiões da 354 — Aplicativo PWA

Projeto independente do site atual do motoclube.

## Objetivo
Aplicativo instalável em Android e iPhone, com acesso exclusivo para membros, agenda de passeios e eventos e notificações.

## Segurança e arquitetura
- Este repositório é separado do site `guardioes-354`.
- Não reutilizar o projeto Supabase do site atual.
- Não armazenar senhas ou chaves secretas no código-fonte.
- A autenticação e o banco de dados serão configurados em um projeto novo.

## Estado atual
Estrutura inicial do PWA em preparação. Nenhuma integração de autenticação ou banco de dados está ativa ainda.
